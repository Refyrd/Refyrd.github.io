# Платформа браузерных мини-игр

Адаптивный и доступный веб-портал в виде аппаратной ретро-консоли для браузерных мини-игр, размещаемый на GitHub Pages.

[English version](README.md)

## Визуальный стиль
Интерфейс выполнен в эстетике **Hardware Pocket Console** (вдохновлен устройствами Teenage Engineering и консолью Playdate). Никаких шаблонных градиентов, тяжелых фреймворков и неработающих кнопок.

## Особенности
- **Чистые веб-стандарты:** Семантический HTML5, модульный CSS и чистый Vanilla JavaScript. Работает без сборщиков и внешних библиотек.
- **Модульная картриджная система:** Каждая игра изолирована в отдельный модуль в каталоге `js/games/`.
- **Тактильные микро-анимации:** Едва заметная пульсация еды, отклик счета при поедании, сглаженные сегменты змейки и легкая встряска экрана при столкновении.
- **Доступность и управление:** Полная поддержка клавиатуры (WASD, стрелки, Space, R), управление свайпами и экранный D-pad для смартфонов (кнопки от 48px).
- **Звуковой отклик:** Встроенный мини-синтезатор на Web Audio API (выключен по умолчанию, переключается кнопкой SOUND).
- **Высокий контраст:** Полное соответствие стандартам WCAG AA.

## Доступные игры
1. **Змейка (Слот 01):** Дискретное плавное движение, микро-анимации, прогрессивное ускорение, сохранение рекорда в localStorage.
2. **Слот 02:** Свободный слот под следующую игру.
3. **Слот 03:** Свободный слот под следующую игру.

## Локальный запуск
Проект открывается напрямую в любом браузере либо через локальный сервер:

```bash
# Через встроенный сервер Python
python -m http.server 8000
```
