# Refyrd Games // Портал браузерных мини-игр

Чистый и адаптивный каталог легких браузерных игр, созданный для GitHub Pages.

[English version](README.md)

## Архитектура
- **Главная страница (`/`):** Просторное меню выбора игр с выверенными отступами, правильной типографикой и понятным описанием каждой механики.
- **Изолированные страницы игр (`/игра/`):** Каждая игра находится в отдельной папке (`/snake/`, `/arkanoid/`). На странице игры размещены только игровое поле, статусная панель, удобное управление и кнопка быстрого возврата в каталог.

## Оформление и доступность
- Единая 8px модульная сетка отступов без перекосов и скученности.
- Читаемый системный шрифт без искажений с выверенным межстрочным интервалом.
- Защита от случайной прокрутки экрана во время игры пальцем или мышью (`touch-action: none`).
- Тактильные состояния кнопок и фокус для клавиатуры (стандарт WCAG AA).

## Каталог игр
1. **Змейка (`/snake/`):** Классическая механика с нарастающей скоростью, деликатной пульсацией еды, жестовым управлением свайпами, условием полной победы и скрытым меню отладки.
2. **Арканоид (`/arkanoid/`):** Аркадный крушитель кирпичей с физикой рикошетов от ракетки под разными углами, укрепленными блоками на 2 удара, искрами частиц, 3 жизнями и плавающим окном отладки.
3. **Слот 03:** В разработке.

```bash
python -m http.server 8000
```
