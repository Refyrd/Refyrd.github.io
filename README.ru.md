# Refyrd Games // Портал браузерных мини-игр

Чистый и адаптивный каталог легких браузерных игр, созданный для GitHub Pages.

[English version](README.md)

## Архитектура
- **Главная страница (`/`):** Просторное меню выбора игр с выверенными отступами, правильной типографикой и понятным описанием каждой механики.
- **Изолированные страницы игр (`/игра/`):** Каждая игра находится в отдельной папке (например, `refyrd.github.io/snake/`). На странице игры размещены только игровое поле, статусная панель, удобное управление и кнопка быстрого возврата в каталог.

## Оформление и типографика
- Единая 8px модульная сетка отступов без перекосов и скученности.
- Читаемый системный шрифт без искажений с выверенным межстрочным интервалом.
- Тактильные состояния кнопок, фокус для клавиатуры (стандарт WCAG AA) и кнопки управления от 44px для сенсорных экранов.

## Каталог игр
1. **Змейка (`/snake/`):** Классическая механика с нарастающей скоростью, деликатной пульсацией еды, экранным джойстиком для смартфонов и сохранением рекорда в памяти браузера.
2. **Слот 02:** В разработке.
3. **Слот 03:** В разработке.

## Запуск
Сайт состоит из чистого HTML, CSS и JavaScript. Его можно запустить локально без сборки:

```bash
# Через встроенный сервер Python
python -m http.server 8000
```
