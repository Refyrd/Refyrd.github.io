# Платформа браузерных мини-игр

Адаптивный и доступный веб-портал с легкими мини-играми для браузера, размещаемый на GitHub Pages.

[English version](README.md)

## Особенности
- **Чистый веб-стек:** Создано на современном HTML5, CSS3 и Vanilla JavaScript без тяжелых фреймворков и лишних зависимостей.
- **Индивидуальный дизайн:** Разработано без шаблонных решений AI (AntiSlop подход) с акцентом на тактильный отклик и характер.
- **Доступность:** Полное управление с клавиатуры (Tab, Enter, Space, Escape), высокий цветовой контраст (стандарт WCAG AA) и понятные состояния элементов.
- **Мобильная адаптивность:** Комфортная игра на смартфонах и планшетах с поддержкой сенсорного ввода (минимальный размер кнопок от 44px).

## Структура проекта
```text
Refyrd.github.io/
├── index.html        # Каталог игр и каркас платформы
├── css/              # Таблицы стилей и темы
├── js/               # Логика платформы и запуск игр
├── games/            # Изолированные модули мини-игр
├── TODO.md           # Дорожная карта и статус задач
├── README.md         # Основная документация (на английском языке)
└── README.ru.md      # Документация на русском языке
```

## Локальный запуск
Проект не требует компиляции или сборки. Его можно запустить через любой локальный веб-сервер или расширение Live Server в VS Code:

```bash
# С помощью стандартного Python
python -m http.server 8000

# Либо открыв index.html прямо в браузере
```
