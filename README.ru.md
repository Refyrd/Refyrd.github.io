# Refyrd Games // Портал браузерных мини-игр

Чистый и адаптивный каталог легких браузерных игр, созданный для GitHub Pages.

[English version](README.md)

## Архитектура
- **Главная страница (`/`):** Просторное меню выбора игр с выверенными отступами, правильной типографикой и понятным описанием каждой механики.
- **Изолированные страницы игр (`/игра/`):** Каждая игра находится в отдельной папке (`/snake/`, `/arkanoid/`). На странице игры размещены только игровое поле, статусная панель, удобное управление и кнопка быстрого возврата в каталог.

## Оформление и доступность
- Реализована спецификация Apple Design System (`.AI/DESIGN.md`).
- Заголовки SF Pro Display с плотным межбуквенным интервалом, основной текст 17px.
- Фирменный цвет Action Blue (`#0066cc`) для всех интерактивных кнопок и ссылок на фоне светлого пергамента (`#f5f5f7`).
- Тактильный отклик кнопок со сжатием `scale(0.95)`, фокусные рамки (`2px solid #0071e3`) по стандарту WCAG AA.
- Отсутствие лишних градиентов и теней на интерфейсе, единственный мягкий рассеянный свет под экраном игры.
- Защита от случайной прокрутки экрана во время игры пальцем или мышью (`touch-action: none`).

## Каталог игр
1. **Змейка (`/snake/`):** Классическая механика с нарастающей скоростью, деликатной пульсацией еды, жестовым управлением свайпами, условием полной победы и скрытым меню отладки.
2. **Арканоид (`/arkanoid/`):**
   - Сетка 18x14 из аккуратных квадратных блоков 18px с выразительными геометрическими узорами.
   - 60 уровней с цветными блоками разной прочности (1, 2 и 3 удара) и неразрушимыми стальными преградами с узкими проходами в 1 блок во внутренние хранилища.
   - Бесконечный рандомный режим с 20 геометрическими силуэтами, 10 цветовыми темами и сбалансированной сложностью.
   - Сниженная скорость шарика для комфортной и плавной игры.
   - Выпадающие бонусы (+3 дополнительных шара, x3 утроение текущих шаров на поле, расширение ракетки и редкий нижний защитный барьер).
   - Меню выбора уровней с сохранением прогресса на устройстве (`localStorage`).
   - Плавающее окно отладки для тестирования уровней и бонусов.
3. **Слот 03:** В разработке.
